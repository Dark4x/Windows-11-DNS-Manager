# Windows-11-DNS-Manager
Windows 11 DNS Manager — легковесная утилита  для быстрой настройки DNS. Позволяет в один клик переключаться между DHCP и статическими серверами, поддерживая протокол DNS over HTTPS (DoH) для приватного серфинга. Оптимизировано под интерфейс Windows 11. Безопасно, открыто и эффективно. Для работы требуются права администратора.
